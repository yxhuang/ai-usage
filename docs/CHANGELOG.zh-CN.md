## [Unreleased]

### 新增

- **`python -m server.doctor` 部署自检。** 一条命令报告三家的通断、当前生效配置的来源，
  以及没通的那家缺什么、怎么补——文案与面板里显示的是同一套。退出码 `0` 表示没有待办
  （`~` 降级但有数据可用不算）；`1` 表示有 `✗` 项需要处理。`deploy/install.sh` 装完会
  自动跑一次，诊断不通过不影响安装的退出码。

### 修复

- **Claude 的 HTTP 403 不再误报为登录过期。** 403 是网络层拒绝了到 `api.anthropic.com`
  的连接，现在卡片指向网络与 `providers.claude.proxy` 配置，而不是让你重新登录。
  只有 401 保留原来的重新登录引导。
- **Kimi 缺 key 的提示区分运行环境。** systemd 的 unit 只注入 `PATH`，shell 里 export
  的变量根本到不了服务进程——以 systemd 运行时提示里不再把环境变量列为选项，
  直接指向 `config.toml` 的 `api_key` / `api_key_file`，省得白折腾一轮。

## [0.3.0] — 2026-08-02

这一版主要是把项目从「只在作者机器上能跑」改成别人 clone 下来就能用，
外加一个跟随编辑器启动的开关。

### 破坏性变更

- **内置默认值改成通用值。** 之前发布的默认值其实是作者的私人环境：Claude 和 Codex 默认
  走 `http://127.0.0.1:7890` 代理、Codex 命令是私有的包装脚本 `codex-nowin`、Kimi 的密钥
  文件指向 `~/.config/shell/secrets.sh`。别人 clone 下来三家一个都连不上。现在的默认值是
  三家全部直连、Codex 命令为 `codex`、不配密钥文件（Kimi 依次回退到 `api_key` 和
  `KIMI_API_KEY`）。如果你的环境恰好和旧默认值一致，请在 `config.toml` 里显式写出来，
  模板见 `config.example.toml`。

### 新增

- **`python -m server.launch` 入口，支持 `--config` 指定配置文件路径。**
  显式指定的路径采用严格语义：文件不存在、不是普通可读文件、TOML 解析失败都会直接报错
  退出，不会静默回落到默认配置。不带 `--config` 时行为与原来的 `python -m server.main`
  一致。
- **跟随编辑器启动，带开关**（[`deploy/vscode-hook.sh`](../deploy/vscode-hook.sh)）。
  打开 VSCode 时确认 daemon 在跑并把面板窗口带出来，关掉编辑器就不管。
  开关做在面板里：标题左边一个齿轮，点开是设置视图。它与卡片**互斥显示**，不是加在卡片
  下面的一栏 —— 加在下面的话，卡片一填满小窗口它就被挤到可视区外，这个坑真踩过。
  齿轮也是以后加别的设置的入口。钩子没装时它会直说，而不是给一个点了没用的开关。
  命令行的 `--enable` / `--disable` / `--status` 读写同一个状态。状态就是一个标志文件
  `~/.config/ai-usage/vscode-hook.disabled`，除它之外脚本不往系统里写任何东西。
  重复调用不会开出第二个窗口。

  没有做开机自启：开机时未必要干活，而打开编辑器基本等于要干活了。真想要开机自启的话，
  各系统自带的机制（`shell:startup`、登录项、systemd unit）已经够用，
  没必要再包一层。

- **写操作端点加了防护。** `PUT /api/vscode-hook` 和原有的 `POST /api/refresh` 现在要过
  三道校验：Host 必须是本机回环地址（挡 DNS rebinding）、必须带 `X-Requested-By` 自定义头、
  Origin 必须存在且匹配。第二道是主防线：跨域请求带非 safelisted 自定义头必然触发预检，
  而本服务不注册任何 CORS 中间件，预检必然失败。另外所有响应都下发
  `Content-Security-Policy: frame-ancestors 'none'` 和 `X-Frame-Options: DENY`，
  防止把面板套进透明 iframe 骗你点开关——那种攻击里请求由面板自己发出，前三道全都合法。

### 变更

- **代理语义收敛成两种状态，而且「直连」是真的直连。** 不写、写空串、写纯空白都表示直连；
  写非空 URL 表示走该代理。在此之前代理根本没法关掉：不写会因为配置合并保留内置默认值，
  写空串会让 httpx 抛异常，而且就算归一化成「无代理」也还是会漏——httpx 默认会读
  `HTTP_PROXY` 这类环境变量，Codex 的 app-server 子进程还会继承完整的父进程环境。
  现在没配代理时，Claude 的客户端用 `trust_env=False` 创建，Codex 子进程环境里的大小写
  代理变量（含 `ALL_PROXY` 和 `NO_PROXY`）会在应用配置之前被主动清掉。Kimi 也补上了可选
  的 `proxy`，方便受限网络下使用。
- **失败退避从 10 分钟起改成 60 秒起。** 原来的延迟是 `interval_seconds * 2 ** 失败次数`，
  按默认 5 分钟间隔算，一次失败就把下次尝试推到 10 分钟后，三次就顶到 30 分钟上限。
  结果是网络早就恢复了，某家还黑着。现在改成
  `first_retry_seconds * 2 ** (失败次数 - 1)`，即 60 秒、120 秒、240 秒依次翻倍，
  上限仍是 `max_backoff_seconds`。新增配置项 `poller.first_retry_seconds`。
- **轮询失败的日志级别从 INFO 提到 WARNING**，这样在 uvicorn 的默认日志配置下也能留下来。
  之前有过一次连续十二小时超时，`journalctl` 里一行都没有。日志内容仍然只有 provider 名
  和状态，不含错误正文，因为正文可能带着含 token 的 URL。
- **错误卡片和登录过期卡片现在会显示最后一次尝试的时间**（「最后尝试 3 分钟前」）。
  之前只有 `stale` 卡片带时间，失败的卡片看不出是一分钟前还是一下午之前的事。
  措辞和 `stale` 卡片的「数据来自 ...」不同，因为错误卡片背后没有数据，只有一次尝试。
- **导入 `server.main` 不再有副作用。** 原来模块级就有 `app = create_app()`，导入即建应用。
  现在移进 `main()` 里。

### 修复

- **设置界面改由 `app.js` 生成，不写在 `index.html` 里。** 同一个根因咬了两次：界面元素
  写在会被浏览器缓存的文件里，而驱动它的脚本带 `no-cache`、永远是新的，于是出现
  「新脚本 + 旧 DOM」。第一次是接线时抛异常，把整个面板带崩 —— 数据层明明一切正常，
  窗口却是白的。加了空值判断不崩了，第二次就变成静默消失：齿轮压根不出现，
  而且怎么刷新都没用，因为缓存里那份 HTML 从来就没有它。
  结论是**哪一方保证最新，就由哪一方负责建元素**，所以现在由脚本创建，
  `index.html` 只留骨架。
- **`/`（index.html）也改为 `Cache-Control: no-cache`。** 之前只给了 `/static` 下的资源，
  唯独漏了页面本身这个入口。这条该补，但要清楚它只对**之后**的加载有效 ——
  已经躺在浏览器缓存里的那一份它管不着，所以真正解决问题的是上面那条。
- **静态资源改为 `Cache-Control: no-cache`。** 面板是个长期开着的 Chrome `--app` 窗口，
  CSS 直接走内存缓存，普通刷新都不回源。结果是样式改完了、HTTP 响应也是新的，
  窗口里却看不到变化，非得硬刷新。回环地址上缓存这点东西没有收益。
- **修正了 `KimiProvider` 的 docstring**，原文根据 `trust_env=False` 声称该 provider
  「禁止走代理」。那个标志只表示忽略环境变量里的代理设置；代理开 TUN 模式时是在 IP 层
  拦截的，这个模块根本看不见。网络行为没有变化，只是原来的说法不对。
- **节奏刻度现在是亮的。** 原来是一条 `opacity: 0.34` 的 2px 细线，也就是说整个面板围绕
  着做的那个东西反而最难看清，而它本来是要在一个小窗口里被一眼扫到并拿来比对的。
  现在它有一个两端各探出 2px 的实心核心、一圈保证它压在品牌色填充上也不糊的描边，
  以及两层光晕（深色模式下是发光，浅色模式下是投影）。它仍然是墨色而不是红色：
  红色在这里已经专指「用量 ≥90%」，再来一个含义不同的红会让两个信号都变钝。
  注意 `.bar` 特意不再设 `overflow: hidden`，那会把探出部分和光晕一起裁掉。

### 文档

- **中文 README 重写**，顺带补了一份中文更新日志（就是本文件）。
- 之前设计过一套跨平台的登录自启动开关，方案定稿后**放弃实现**，设计文档作为存档保留在
  [`docs/specs/2026-08-02-autostart-design.md`](specs/2026-08-02-autostart-design.md)。
  放弃的原因是复杂度和收益不成比例：「不开启就不碰用户系统」加上「随时可完全恢复」这两
  条约束，叠加四个平台各不相同的启动机制，需要归属标记、冲突识别、跨进程锁和逐步补偿
  才能站得住，而它解决的问题本来就不是这个项目想要的。存档里记了一些查证过的事实，
  日后真要做可以直接用。

## [0.2.0] — 2026-07-27

托盘交互返工。挂件会进入点了托盘图标没反应的状态，其中一种不杀进程就恢复不了。

### 新增

- 托盘图标支持**单击**显示/隐藏，和微信、QQ 以及多数 Windows 托盘应用一致。双击仍然
  有效：Windows 会把一次双击派发成「单击 + 双击 + 单击」，多余的第二次单击会被吞掉，
  所以不会出现显示完立刻又隐藏。
- `tests/tray-click-filter.ps1` 覆盖点击接受规则。它通过 PowerShell AST 把
  `tray-widget.ps1` 里真正的 `Test-AcceptClick` 取出来测，而不是测一份复制出来的副本。
  只能在 Windows 上跑，Linux 的 CI 会跳过。

### 修复

- **最小化按钮会让挂件再也找不回来。** 窗口带 `WS_EX_TOOLWINDOW`，不在任务栏里，
  最小化之后会缩成屏幕角落的一个小条，没有任何办法还原。这里有三个 Win32 细节凑在一起：
  最小化的窗口 `IsWindowVisible` 仍然返回 true；`SW_SHOW` 不会清除最小化标志（所以
  「显示」它只会再得到那个小条）；`GetWindowRect` 返回的是小条的尺寸（实测 159×27），
  而这个尺寸会被当成面板位置存下来。现在最小化的窗口会像点关闭一样被收进托盘，
  显隐判断连 `IsIconic` 一起看，重新显示用 `SW_RESTORE`，最小化期间不记录位置，
  记下来的尺寸小于 200px 一律丢弃。
- **冷启动期间的点击会被回放。** 从标题栏 X 关掉之后再打开需要几秒（Chrome 要启动），
  这期间 UI 线程是阻塞的，等得不耐烦多点的几下会排队，然后在面板刚出现的一瞬间集中送达，
  把窗口又关回去。现在点击过滤按消息的**投递**时间（`GetMessageTime`）判断，
  而不是按处理时间，上一次动作完成之前投递的一律丢弃。
- **定位面板窗口不可靠。** `Get-Process().MainWindowTitle` 一个进程只报一个窗口，
  报哪个取决于 Z 序，而且窗口一隐藏 `MainWindowHandle` 就变成 0。冷启动时找不到会导致
  20 秒超时并弹一个错误气泡。现在改成用 `EnumWindows` 直接枚举顶层窗口，
  再确认所属进程属于挂件自己的浏览器 profile。

### 变更

- 显隐状态改为从操作系统读（`IsWindowVisible` + `IsIconic`），不再用脚本自己维护的
  `$script:Visible` 标志，那个标志可能和真实窗口状态不一致。
- 看门狗间隔从 800ms 改成 400ms，最小化的窗口在小条被注意到之前就收进托盘。

### 文档

- 记录了挂件跑在 **Windows PowerShell 5.1** 上（`launcher.vbs` 调的是 `powershell.exe`），
  以及为什么故意不用 PowerShell 7：5.1 是系统自带的，不会被从自启动项底下卸载掉，
  启动还快约 100ms（实测 150–180ms 对 250–265ms）。挂件用到的机制在两者上都能用。
- 提醒 PowerShell 7 默认写文件**不带 BOM**。这些脚本必须保持带 BOM 的 UTF-8，
  否则 5.1 会按 ANSI 解码中文注释并解析失败。从 `pwsh` 里重写要加 `-Encoding utf8BOM`。
- 提醒 `install-widget.ps1` 是把脚本**复制**到 `%LOCALAPPDATA%\ai-usage\`，
  改仓库不会影响正在跑的挂件，得重跑一次。

## [0.1.0] — 2026-07-26

首个公开版本：一个面板显示 Claude、Codex、Kimi 三家的订阅额度。

### 新增

- 三家的额度轮询，带离线缓存，某家不可达时面板照样能渲染。
- 只绑回环地址的网页面板，按常驻小窗口的尺寸设计：每家一张卡片、品牌配色、
  每根条上都有标记时间窗口进度的节奏刻度，额外 credit 池按金额显示。
- 用于后台常驻的 systemd user unit。
- 零安装的 Windows 托盘挂件（`deploy/tray-widget.ps1`）：一个从外部改过样式的 Chrome
  `--app` 窗口，不占任务栏和 Alt+Tab，标题栏的关闭按钮被翻译成「收进托盘」而不是退出。
- `deploy/install-widget.ps1`，用来安装挂件并把已有快捷方式改指到它，
  中间过一层 VBS 以免启动时闪黑框。
- 68 项离线测试、MIT 许可、CI，以及中英双语 README。
